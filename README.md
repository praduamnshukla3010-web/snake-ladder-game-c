# Snake and Ladder Game (C Language)

A terminal-based Snake and Ladder game developed in C as a Project-Based Learning (PBL) assignment by 2nd Semester students of Electronics and Communication Engineering (ECE).

## Project Objective

To understand and implement fundamental programming concepts using C, including:

- Loops and conditionals  
- Functions  
- Arrays  
- Random number generation  
- Game logic design  

---

## Game Features

- Dice roll simulation  
- Two-player gameplay  
- Snakes (move down on landing)  
- Ladders (move up on landing)  
- Terminal-based board display  
- Turn-based system  

---

## Snakes and Ladders Positions

Snakes:
- 25 to 9  
- 65 to 40  
- 99 to 1  

Ladders:
- 13 to 42  
- 60 to 83  
- 70 to 93
